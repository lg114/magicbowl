# 用设计令牌统一你的界面

当你在第 50 个组件里手写 `#4163e9` 时，改一次主题就会变成灾难。设计令牌就是为了解决这个问题。

## 什么是设计令牌

设计令牌是**设计决策的最小单元**：颜色、间距、圆角、阴影……它们以变量的形式存在，被所有组件引用。

```css
:root {
  --primary: #4163e9;
  --surface: rgba(255, 255, 255, 0.06);
  --border: rgba(255, 255, 255, 0.12);
}
```

## 主题切换

把同一组令牌在 `data-theme="light"` 下重新赋值，整站风格随之翻转：

```css
:root[data-theme="light"] {
  --bg: #f6f7f9;
  --text: #16191f;
}
```

> 组件从不直接写死颜色，只引用令牌。这是可维护性的根本。

一个小小的 `--primary`，撑起了整个站点的视觉一致性。
